# Worship Song Looper - Quick Reference

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `1-9` | Jump to Region 1-9 (quantized) |
| `L` | Toggle Loop |
| `[` | Set Loop Start |
| `]` | Set Loop End |
| `M` | Toggle Metronome |
| `F` | Toggle Stage Mode |
| `Q` | Queue Region |
| `Esc` | Exit Stage Mode |

## Workflow

1. **Import** → Generate demo or drag audio file
2. **Analyze** → Beats detected automatically
3. **Create Regions** → Mark Intro, Verse, Chorus, etc.
4. **Practice** → Jump between sections with number keys
5. **Loop** → Press `[` at start, `]` at end, `L` to loop
6. **Queue** → While looping, press `Q` to queue next section
7. **Stage Mode** → Press `F` for full-screen performance view

## Tips

- **Quantize**: Jumps snap to bar boundaries for musical timing
- **Queue**: Set up next section while current one loops
- **Crossfade**: Adjust duration in settings for smooth transitions
- **Confidence**: Green = high, yellow = medium, red = low beat detection
- **Stage Mode**: Perfect for tablets during worship sessions
